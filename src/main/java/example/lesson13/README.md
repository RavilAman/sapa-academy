# 📝 Домашнее задание: Аудит изменений зарплаты сотрудников

## 📌 Условие задачи

В базе данных есть таблицы сотрудников **`employees`** и таблица аудита изменений зарплаты **`salary_audit`**:

```sql
CREATE TABLE employees (
    id BIGSERIAL PRIMARY KEY,
    name TEXT NOT NULL,
    salary NUMERIC(10,2) NOT NULL,
    updated_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE salary_audit (
    id BIGSERIAL PRIMARY KEY,
    employee_id BIGINT NOT NULL,
    old_salary NUMERIC(10,2),
    new_salary NUMERIC(10,2),
    changed_at TIMESTAMPTZ DEFAULT now()
);
```

---

## 🎯 Задача

1. ✍️ **Написать функцию** (на PL/pgSQL), которая будет:
    - при обновлении зарплаты у сотрудника сохранять **старое и новое значение** в таблицу `salary_audit`.

2. ⚡ **Создать триггер**, который:
    - будет срабатывать **AFTER UPDATE** на таблице `employees`,
    - вызывать функцию аудита,
    - записывать изменения зарплаты **только если действительно поменялось поле `salary`**.

---

## ✅ Что нужно сделать

1. Создать таблицы `employees` и `salary_audit`.
2. Заполнить таблицу `employees` тестовыми данными (например, 3–4 сотрудника).
3. Реализовать функцию `audit_salary_changes`.
4. Создать триггер `trg_audit_salary`.
5. Проверить работу:
    - выполнить `UPDATE employees SET salary = ... WHERE id = ...;`
    - убедиться, что в таблице `salary_audit` появилась запись об изменении.
